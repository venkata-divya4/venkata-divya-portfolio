# venkata Divya — Portfolio

A modern, high-performance developer portfolio showcasing full-stack web applications, machine learning projects, and software engineering capabilities.

**Live site:** https://protfolio-beta-brown-33.vercel.app/

## Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS 4**
- **Framer Motion**
- **AOS (Animate On Scroll)**
- **EmailJS**
- **WebGL**

## Run Locally

Clone the repository and install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Environment Variables

To enable the contact form via EmailJS, create a `.env.local` file in the root directory and configure the following variables:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
